# Cupcake Express 🍰

Sistema web simples desenvolvido como projeto acadêmico de Engenharia de Software para uma loja virtual de cupcakes gourmet.

## Descrição

O Cupcake Express permite visualizar cupcakes, adicionar itens ao carrinho, informar dados de entrega, selecionar pagamento simulado e gerar resumo do pedido. O projeto foi criado com React + Vite e pode ser hospedado gratuitamente na Vercel.

## Tecnologias

- React
- Vite
- JavaScript
- CSS
- Lucide React
- Vercel

## Como rodar localmente

```bash
git clone https://github.com/SEU-USUARIO/cupcake-express.git
cd cupcake-express
npm install
npm run dev
```

Acesse:

```txt
http://localhost:5173
```

## Deploy na Vercel

Configuração recomendada:

```txt
Framework Preset: Vite
Install Command: npm install
Build Command: npm run build
Output Directory: dist
```
